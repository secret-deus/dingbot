# 前端访问密码设置指南

## 功能概述

为了保护系统安全，前端现在需要输入访问密码才能进入系统。

## 默认密码

**默认访问密码**: `ding2024`

## 自定义密码

### 方法1: 环境变量（推荐）

创建 `frontend/.env` 文件：

```bash
# 前端访问密码
VITE_ACCESS_PASSWORD=your_custom_password

# 应用配置
VITE_APP_TITLE=钉钉K8s运维机器人
VITE_APP_VERSION=1.0.0
```

### 方法2: 修改代码

编辑 `frontend/src/views/Login.vue` 文件，修改第58行：

```javascript
const DEFAULT_PASSWORD = import.meta.env.VITE_ACCESS_PASSWORD || 'your_custom_password'
```

## 功能特性

### 🔐 安全特性
- **密码验证**: 输入正确密码才能访问系统
- **会话管理**: 登录状态保持24小时
- **自动过期**: 超时自动退出登录
- **路由守卫**: 未登录自动跳转到登录页

### 🎨 用户体验
- **美观界面**: 现代化登录页面设计
- **响应式布局**: 支持手机和桌面端
- **密码显示**: 支持显示/隐藏密码
- **回车登录**: 支持回车键快速登录
- **加载状态**: 登录过程显示加载动画

### 🔄 会话管理
- **自动跳转**: 登录成功后跳转到之前访问的页面
- **状态持久**: 页面刷新后保持登录状态
- **安全退出**: 支持手动退出登录
- **过期提醒**: 会话过期自动清理

## 使用流程

1. **访问系统**: 打开前端地址 http://localhost:5173
2. **输入密码**: 在登录页面输入访问密码
3. **进入系统**: 验证成功后自动跳转到仪表板
4. **退出登录**: 点击右上角用户头像 → 退出登录

## 技术实现

### 文件结构
```
frontend/src/
├── views/Login.vue          # 登录页面组件
├── utils/auth.js           # 认证工具函数

└── App.vue                 # 主应用布局
```

### 核心功能
- **路由守卫**: 自动检查登录状态
- **本地存储**: 使用localStorage保存登录状态
- **会话过期**: 24小时自动过期机制
- **状态响应**: 实时响应登录状态变化

## 安全建议

1. **生产环境**: 务必修改默认密码
2. **环境变量**: 使用环境变量设置密码，不要硬编码
3. **定期更换**: 建议定期更换访问密码
4. **访问控制**: 结合网络防火墙等措施加强安全

## 故障排查

### 常见问题

**Q: 忘记密码怎么办？**
A: 检查 `frontend/.env` 文件或 `Login.vue` 中的默认密码设置

**Q: 登录后页面空白？**
A: 检查浏览器控制台错误，可能是路由配置问题

**Q: 会话经常过期？**
A: 检查系统时间，或修改 `auth.js` 中的过期时间设置

**Q: 环境变量不生效？**
A: 确保 `.env` 文件在 `frontend/` 目录下，且重启开发服务器

### 调试模式

在浏览器控制台执行以下命令查看登录状态：

```javascript
// 查看登录状态
console.log('登录状态:', localStorage.getItem('isAuthenticated'))

// 查看登录时间
console.log('登录时间:', new Date(parseInt(localStorage.getItem('loginTime'))))

// 手动清除登录状态
localStorage.removeItem('isAuthenticated')
localStorage.removeItem('loginTime')
```
