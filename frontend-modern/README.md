# 钉钉K8s运维机器人 - 现代化版本

这是钉钉K8s运维机器人前端的现代化版本，采用了全新的设计语言和用户体验。

## 🎨 现代化特性

### 设计系统
- **现代色彩系统**: 采用基于蓝色的现代配色方案，支持语义化色彩
- **统一设计令牌**: 完整的设计系统，包含间距、字体、圆角、阴影等
- **现代字体**: 使用系统字体栈，提供更好的可读性
- **流畅动画**: 采用现代缓动函数和过渡效果

### 用户界面
- **现代化聊天界面**: 重新设计的消息气泡和布局，优化左右边距
- **现代化仪表板**: 全新的统计卡片和资源监控界面
- **现代化设置页面**: 分类清晰的配置管理界面
- **智能供应商选择**: 直观的AI供应商切换界面
- **欢迎屏幕**: 友好的欢迎界面和快速操作卡片
- **工具调用可视化**: 更清晰的MCP工具执行状态显示

### 交互体验
- **流畅过渡**: 所有界面元素都有平滑的过渡动画
- **现代按钮**: 采用现代化的按钮设计和交互反馈
- **响应式设计**: 完美适配桌面和移动设备
- **无障碍支持**: 支持键盘导航和屏幕阅读器

## 🚀 启动方法

### 开发环境
```bash
# 安装依赖
npm install

# 启动开发服务器 (端口 5174)
npm run dev
```

### 访问地址
- **现代化版本**: http://localhost:5174
- **原版本**: http://localhost:5173 (如果同时运行)
