# 新前端使用指南

## 🚀 快速启动

### 1. 启动后端服务
确保后端服务正在运行：
```bash
cd /Users/a123/github.com/ding-robot
poetry run serve
```

### 2. 启动新前端
```bash
cd /Users/a123/github.com/ding-robot/frontend-v2
npm run dev
```

### 3. 访问地址
- **新前端**: http://localhost:5174
- **原前端**: http://localhost:5173 (如需对比)
- **后端API**: http://localhost:8000

## 🐛 故障排查

### 常见问题

#### 1. 页面无法加载
- 检查后端服务是否启动: `curl http://localhost:8000/health`
- 检查前端服务是否启动: 访问 http://localhost:5174

#### 2. API请求失败
- 访问API测试页面进行调试
- 检查浏览器控制台的错误信息
- 确认后端API路径是否正确

#### 3. 聊天功能不工作
- 检查SSE连接是否正常
- 确认后端LLM配置是否正确
- 查看网络面板的EventSource连接

### 调试步骤
1. 访问 `/api-test` 页面测试各个API
2. 查看浏览器开发者工具的Network面板
3. 检查控制台错误日志
4. 对比原前端的API调用方式

## 📝 开发说明

### 技术栈
- Vue 3 + Composition API
- Element Plus UI组件库
- Pinia状态管理
- Vue Router路由
- Axios HTTP客户端
- Sass/SCSS样式

### 项目结构
```
frontend-v2/
├── src/
│   ├── views/          # 页面组件
│   ├── components/     # 通用组件
│   ├── stores/         # Pinia状态
│   ├── api/           # API客户端
│   ├── router/        # 路由配置
│   └── assets/        # 静态资源
├── package.json       # 依赖配置
└── vite.config.js     # 构建配置
```
