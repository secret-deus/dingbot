# 钉钉K8s运维机器人 - 现代化前端界面 v2.0

## 项目概述

这是钉钉K8s运维机器人的现代化重构版前端界面，采用最新的设计系统和用户体验标准，提供更加直观、美观的操作界面。

## 🎨 设计特色

### 现代化设计系统
- **统计卡片容器 (Stats Cards Container)**: 采用现代卡片式布局，信息层次清晰
- **渐变色彩方案**: 使用现代蓝色渐变主题，视觉效果更佳
- **响应式设计**: 完美适配桌面端和移动端设备
- **微交互动画**: 丰富的hover效果和页面切换动画

### 核心UI组件
- **智能卡片系统**: 自动阴影、悬浮效果、状态指示器
- **现代化导航**: 侧边栏导航 + 面包屑导航
- **实时状态显示**: 动态状态指示器和进度条
- **优雅的数据可视化**: 统计数字、趋势图表、使用率显示

## 🚀 技术栈

- **Vue.js 3**: 使用Composition API
- **Element Plus**: 现代化UI组件库
- **Pinia**: 状态管理
- **Vue Router**: 路由管理
- **Sass/SCSS**: CSS预处理器
- **Vite**: 现代化构建工具

## 🎯 核心功能

### 1. 现代化仪表板
- **系统健康监控**: 实时显示MCP客户端、LLM处理器、钉钉机器人状态
- **工具统计**: 可用工具数量、分类统计、运行状态
- **集群资源概览**: 节点、Pod、服务数量，CPU/内存使用率
- **活动统计**: 今日操作、本周操作数量统计
- **实时日志**: 系统操作日志，支持不同级别显示

### 2. 统计卡片系统
每个统计卡片包含：
- **图标标识**: 彩色渐变图标，功能识别度高
- **主要数据**: 大字号显示关键指标
- **趋势信息**: 显示数据变化趋势和状态
- **详细信息**: 展开显示更多详细数据
- **交互效果**: 悬浮动画和点击反馈

### 3. 响应式布局
- **桌面端**: 4列网格布局，充分利用屏幕空间
- **平板端**: 2列网格布局，保持信息密度
- **移动端**: 单列布局，优化触摸操作

## 🎨 设计系统

### 色彩方案
```scss
// 主色调
--primary-color: #2563eb;        // 现代蓝
--primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

// 功能色彩
--success-color: #10b981;        // 成功绿
--warning-color: #f59e0b;        // 警告橙
--danger-color: #ef4444;         // 危险红
--info-color: #06b6d4;           // 信息青

// 中性色调
--text-primary: #1f2937;         // 主文本
--text-secondary: #6b7280;       // 次要文本
--bg-primary: #ffffff;           // 主背景
--bg-secondary: #f8fafc;         // 次要背景
```

### 组件规范
- **卡片圆角**: 12px (--radius-lg)
- **阴影层级**: 4个级别 (sm, md, lg, xl)
- **间距系统**: 8px基准，6个级别
- **字体系统**: 系统字体栈，支持多平台

## 🔧 自定义配置

### 主题定制
修改 `src/assets/css/main.scss` 中的CSS变量：

```scss
:root {
  --primary-color: #your-color;
  --primary-gradient: your-gradient;
  // ... 其他变量
}
```

### API配置
修改 `src/api/client.js` 中的baseURL：

```javascript
const api = axios.create({
  baseURL: '/api/v2',  // 修改为你的API地址
  // ...
})
```
