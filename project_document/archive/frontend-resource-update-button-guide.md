# 前端资源更新按钮使用指南

## 📋 功能概述

新增的"更新资源指标"按钮为用户提供了一个便捷的方式来手动触发Kubernetes资源利用率数据的更新。该功能通过前端界面直接调用后端API，进而触发MCP工具来更新知识图谱中的资源指标数据。

## 🎯 功能特性

### 核心功能
- **一键更新**: 点击按钮即可触发资源指标更新
- **实时反馈**: 显示更新进度和结果统计
- **错误处理**: 完善的错误提示和日志记录
- **状态指示**: 按钮加载状态和系统日志更新

### 技术特性
- **异步处理**: 非阻塞的后台更新过程
- **批量更新**: 支持并发更新多个deployment
- **重试机制**: 自动重试失败的更新操作
- **覆盖保障**: 确保所有deployment都被更新

## 🚀 使用方法

### 1. 启动服务

```bash
# 1. 启动MCP服务器
poetry run python k8s-mcp/start_k8s_mcp_http_server.py

# 2. 启动后端服务
poetry run serve

# 3. 访问前端界面
# 浏览器打开: http://localhost:5173
```

### 2. 使用按钮

1. **访问Dashboard**: 在前端界面中导航到"系统仪表板"页面
2. **找到按钮**: 在页面顶部的操作区域找到"更新资源指标"按钮（橙色警告色）
3. **点击更新**: 点击按钮开始更新过程
4. **查看进度**: 观察按钮的加载状态和系统日志的实时更新
5. **查看结果**: 更新完成后会显示成功消息和统计信息

### 3. 结果解读

更新完成后，系统会显示以下信息：
- **总应用数**: 发现的deployment总数
- **成功更新**: 成功更新指标的deployment数量
- **失败更新**: 更新失败的deployment数量
- **处理时间**: 整个更新过程耗时

## 🔧 技术架构

### 数据流向
```
前端Dashboard按钮 
    ↓
后端API (/v2/resources/update-metrics)
    ↓
MCP工具 (k8s-update-knowledge-graph-metrics)
    ↓
知识图谱更新 (K8sKnowledgeGraph)
    ↓
Prometheus数据聚合 (MetricsAggregator)
```

### 关键组件

#### 前端组件
- **文件**: `frontend/src/views/Dashboard.vue`
- **方法**: `onUpdateResourceMetrics()`
- **状态**: `resourceUpdateLoading`
- **图标**: `DataAnalysis`

#### 后端API
- **文件**: `backend/src/api/v2/endpoints/resources.py`
- **端点**: `POST /v2/resources/update-metrics`
- **模型**: `ResourceUpdateRequest`, `ResourceUpdateResponse`

#### MCP工具
- **文件**: `k8s-mcp/src/k8s_mcp/tools/k8s_update_knowledge_graph_metrics.py`
- **工具名**: `k8s-update-knowledge-graph-metrics`
- **功能**: 批量更新知识图谱中的资源指标

## ⚙️ 配置参数

### 默认参数
```javascript
{
  days: 14,              // 分析过去14天的数据
  maxConcurrent: 5,      // 最大并发更新数
  forceUpdate: false     // 是否强制更新
}
```

### 可调整参数
- **namespace_filter**: 命名空间过滤器（空表示所有命名空间）
- **app_name_filter**: 应用名称过滤器（空表示所有应用）
- **days**: 数据分析天数（默认14天）
- **max_concurrent**: 最大并发数（默认5）
- **force_update**: 是否强制更新（默认false）

## 📊 性能优化

### 批量处理
- **并发控制**: 限制同时处理的deployment数量
- **分批更新**: 大量数据分批处理
- **内存管理**: 及时释放不需要的数据

## 🛠️ 故障排查

### 常见问题

#### 1. 按钮无响应
- **检查**: MCP服务器是否正常运行
- **解决**: 重启MCP服务器

#### 2. 更新失败
- **检查**: Prometheus服务器连接
- **解决**: 验证Prometheus配置

#### 3. 部分更新失败
- **检查**: 系统日志中的错误详情
- **解决**: 根据具体错误信息处理

#### 4. 性能问题
- **检查**: 并发数设置是否合理
- **解决**: 调整max_concurrent参数

### 日志位置
- **MCP服务器日志**: `k8s-mcp/logs/k8s-mcp.log`
- **后端服务日志**: `backend/logs/app.log`
- **前端控制台**: 浏览器开发者工具
